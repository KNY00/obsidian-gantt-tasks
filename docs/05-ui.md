# UI & Interactive Features

Unlike standard static Dataview queries, this script generates an interactive user interface directly within your note. Once the script runs, it renders a centered container holding both the Gantt chart and a set of controls.

Here is a breakdown of the interactive elements you can use:

## 1. Timeline Navigation (Prev & Next)

You do not need to manually change the script's configuration every time you want to look at a different day. The UI includes built-in navigation buttons grouped at the top of the container.

*   **Next Button:** Clicking this shifts the timeline forward by one day. It dynamically increments a hidden day offset and automatically re-renders the Mermaid chart with the new day's tasks.
*   **Prev Button:** Clicking this shifts the timeline backward by one day, decrementing the offset.
*   **Active Date Display:** Sandwiched between the two navigation buttons is a small text indicator that displays the current date being filtered and rendered on the chart.

::: info Performance
To prevent overlapping renders, the buttons temporarily disable themselves while the new chart is generating. 
:::

## 2. Toggle Tasks List

Sometimes a Gantt chart can become visually crowded if you have many short tasks. To help you get a clear overview, the script provides a **Toggle Tasks** button.

*   **Behavior:** Clicking this button expands or collapses a hidden list (`ul`) directly beneath the controls.
*   **Content:** When expanded, it displays a clean, text-based list of all the valid tasks that are currently being rendered on the timeline.
*   **Formatting:** Each item in the list automatically extracts and displays its time interval as a prefix (e.g., `[09:00 - 10:30]`) followed by the cleaned-up task name.

## 3. Diagram Text Cropping

To maintain a clean layout and prevent visual clutter or overflow issues, long task names within the Mermaid diagram are automatically cropped to fit the timeline slots cleanly. You can always view the full, uncropped task names by using the **Toggle Tasks** list described above.
